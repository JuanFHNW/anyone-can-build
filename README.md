# Restaurant Group Order (Mock)

A small responsive web app demonstrating group ordering, per-person assignment, and split-bill checkout.

Run locally:

```bash
npm install
npm run dev
```

Open http://localhost:5173

Features:

- Start a session and add member names.
- Browse menu and assign items to members.
- View cart, per-person breakdown, tax calculation, and totals.
- Mock checkout where each person can select payment method and pay their share.

Built with React + Vite (minimal mock data).
